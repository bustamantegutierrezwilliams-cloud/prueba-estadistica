# Proyecto de Estadística Descriptiva

## Tema
Uso de Moodle y Siringuero Net en estudiantes universitarios.

## Herramientas utilizadas
- Python
- Pandas
- Matplotlib
- NumPy

## Variables analizadas
- Edad
- Sexo
- Semestre
- Conocimiento de Moodle y Siringuero Net
- Frecuencia de uso de Siringuero Net

## Resultados
Se realizaron tablas de frecuencia y gráficos estadísticos para analizar el uso de plataformas virtuales en estudiantes universitarios.
